# 🚀 GROWIX — منصة التسويق الإلكتروني الشاملة وحزمة الـ 12 أداة

> **GROWIX** هي المنصة العربية الأولى المتكاملة لتوفير كورس تسويق إلكتروني عملي تطبيقي من الصفر للاحتراف، مرفقاً بترسانة برامج وأدوات تسويقية آلية (12 أداة متطورة) + هدية قاعدة بيانات "داتا مصر التسويقية"، بهدف تمكين أصحاب المشاريع، الشركات، المسوقين، وأصحاب المتاجر من مضاعفة مبيعاتهم وأتمتة حملاتهم دون الحاجة لدفع اشتراكات شهرية باهظة.

## 🎯 عن المشروع ورؤية GROWIX

في عالم التسويق الرقمي الحديث، يواجه صاحب أي مشروع أو مسوق إلكتروني مشكلتين رئيسيتين:
1. **ارتفاع تكاليف الاشتراكات الشهرية:** أدوات مثل برامج الإرسال، أدوات سحب البيانات، بدائل التصميم، والمونتاج تستهلك مئات الدولارات شهرياً.
2. **الشتات وقلة الخبرة العملية:** وجود كورسات نظرية بدون أدوات حقيقية للربط والتطبيق المباشر.

جاءت منصة **GROWIX** لتقدم حلاً شاملاً: **اشتراك لمرة واحدة وتفعيل دائم مدى الحياة** بدون مصاريف شهرية، حيث يحصل المشترك على:
- كورس تسويق إلكتروني مسجل بصوت وصورة يشرح التخطيط والإعلانات من الصفر.
- 12 أداة وتسويق تلقائي لأتمتة الرسائل على واتساب، تليجرام، فيسبوك، انستجرام، وتيك توك.
- أدوات سحب الداتا واستخراج العملاء من فيسبوك وجوجل مابس.
- أدوات الذكاء الاصطناعي، التصميم، والمونتاج.
- قاعدة بيانات "داتا مصر التسويقية" مقسمة للمحافظات والأنشطة التجارية.

## 💎 المميزات التنافسية والقيمة الجوهرية

* ♾️ **تفعيل مدى الحياة (No Monthly Subscriptions):** دفعة واحدة فقط بدون أي اشتراكات متكررة.
* ⚡ **تفعيل سريع وتدريب فوري (< 60 دقيقة):** تفعيل يدوي عبر الواتساب واستلام جميع الروابط والشروحات فوراً.
* 🛡️ **تقنية Anti-Block لحماية الحسابات:** تزويد أدوات المراسلة مثل واتساب سندر بمحاكاة سلوك بشري وفواصل زمنية ذكية حمايةً لحساباتك.
* 🎬 **فيديوهات شرح مسجلة لكل أداة:** فيديو خطوة بخطوة لكل أداة يوضح تثبيتها وتشغيلها بكل سهولة.
* 🤝 **دعم فني مباشر 24/7:** فريق دعم متواجد عبر الواتساب وتليجرام لمساعدتك في أي استفسار.
* 🔄 **تحديثات مجانية مستمرة:** مواكبة كافة تحديثات المنصات والتطبيقات مجاناً.

## 🛠️ تفاصيل حزمة الـ 12 أداة التسويقية

| # | اسم الأداة | التصنيف | الوصف الوظيفي والأهمية التسويقية |
|---|------------|---------|-----------------------------------|
| **01** | **فيسبوك بوت (Facebook Marketing Bot)** | `Social` | نشر وجدولة البوستات والفيديوهات في مئات المجموعات والصفحات بضغطة واحدة، رد تلقائي ذكي على التعليقات والرسائل، وإرسال حملات ماسنجر غير محدودة. |
| **02** | **واتساب سندر (WhatsApp Sender Anti-Block)** | `Messaging` | إرسال حتى 1000 رسالة واتساب يومياً بأمان تام وتخصيص الرسائل بأسماء العملاء تلقائياً، مع أداة سحب أرقام أعضاء مجموعات الواتساب. |
| **03** | **تليجرام سندر (Telegram Bulk Sender)** | `Messaging` | إرسال رسائل تليجرام بكميات ضخمة، زيادة أعضاء القنوات والمجموعات، وسحب داتا أعضاء الجروبات المنافسة وإدارة عدة حسابات. |
| **04** | **انستجرام بوت (Instagram Bot)** | `Social` | زيادة متابعين انستجرام الحقيقيين المستهدفين، رد تلقائي فوري على الكومنتات والرسائل الخاصة (DM)، وإرسال رسائل جماعية للعملاء. |
| **05** | **تيك توك بوت (TikTok Bot)** | `Social` | تكبير حساب التيك توك، أتمتة الردود والرسائل المباشرة، ورفع نسبة وصول الفيديوهات وتصدر النتائج. |
| **06** | **أداة زيادة الوصول (Reach Booster)** | `Social` | استخراج الكلمات المفتاحية والدلالية الأكثر بحثاً لأي مجال، وتوليد هاشتاجات سرية لرفع الريتش والوصول المجاني العضوي. |
| **07** | **بديل كانفا برو (Canva Pro Alt)** | `Design` | إنشاء أفضل التصميمات التسويقية والإعلانات، تعديل الصور وإزالة الخلفية بضغطة زر، وقوالب جاهزة للسوشيال ميديا. |
| **08** | **أداة مونتاج وتعديل الفيديو** | `Design` | صناعة ومونتاج الفيديوهات التسويقية والـ Reels والـ Shorts، إضافة النصوص المتحركة والمؤثرات البصرية وتفريغ الصوت. |
| **09** | **VideoScribe (رسوم متحركة ووايت بورد)** | `Design/AI` | إنشاء فيديوهات الرسوم المتحركة والـ Whiteboard Animation بالذكاء الاصطناعي مع مكتبة رسم وأشكال ضخمة جاهزة. |
| **10** | **سحب الداتا (Data Scraper Pro)** | `Data` | سحب أرقام وداتا العملاء والشركات والمحلات من فيسبوك، انستجرام، وجوجل مابس (Google Maps) وتصديرها لملفات Excel مرتبة. |
| **11** | **توليد فيديو بالذكاء الاصطناعي من الصور** | `AI` | تحويل الصور الثابتة إلى فيديوهات ناطقة ومتحركة مبهرة لصناعة إعلانات مبتكرة بدون حاجة لتصوير أو استوديو. |
| **12** | **دولينجو مفتوح (Duolingo Super Unlocked)** | `Education` | تطبيق تعلم اللغات بجميع المستويات والمميزات المدفوعة مفتوحة مجاناً لتطوير المهارات اللغوية والتواصل مع العملاء. |

## 📚 كورس التسويق الإلكتروني الشامل

كورس عملي مسجل بفيديوهات عالية الجودة، ياخذ بيد المشترك من الصفر وحتى الاحتراف:

* 🧠 **استراتيجية التسويق الرقمي:** كيفية تحديد العميل المثالي وصياغة العرض التسويقي (Offer).
* 🏢 **إدارة الأعمال Meta Business Manager:** إنشاء وحماية الحسابات الإعلانية والبيكسل.
* ✍️ **كتابة النصوص الإعلانية (Copywriting):** كتابة إعلانات بيعية تؤثر في قرار الشراء.
* 🎯 **الاستهداف المتقدم:** تحديد الجمهور الصح وتجنب إهدار الميزانية الإعلانية.
* 📊 **إعلانات المنصات:** تنفيذ حملات فيسبوك، انستجرام، جوجل، وتيك توك واحتساب عائد الاستثمار (ROI).
* 🔗 **ربط الأدوات الـ 12:** تطبيق عملي لربط الأدوات بالحملات الإعلانية لمضاعفة النتائج.

## 💻 البنية التقنية والتكنولوجيا المستخدمة

المشروع مبني بأحدث تقنيات الـ Web Development لضمان السرعة، الأمان، والتجاوب التام:

* **Framework:** [Next.js 15.4+](https://nextjs.org/) (App Router, Server Components & Client Components)
* **Library:** [React 19](https://react.dev/) & [TypeScript 5](https://www.typescriptlang.org/)
* **Styling:** Vanilla CSS & [Tailwind CSS 4](https://tailwindcss.com/) مع استخدام `@theme` و `@layer base`
* **Animations:** [Motion (Framer Motion)](https://motion.dev/) للميكرو-أنيميشن والبطاقات
* **Icons:** [Lucide React](https://lucide.dev/) (Tree-shaked عبر Next.js)
* **Fonts:** `IBM Plex Sans Arabic` عبر `next/font/google` لضمان تجربة قراءة سلسة بالعربية
* **OpenGraph Dynamic Images:** توليد صور المشاركة اجتماعياً ديناميكياً بدقة 1200×630 عبر `next/og` (`ImageResponse`)
* **PWA Support:** ملف `manifest.ts` لدعم تطبيقات الويب الهجينة

## 🔍 معمارية تحسين محركات البحث (SEO Architecture)

تم تجهيز المشروع بخطة SEO استراتيجية واحترافية تعتمد على 2,287 كلمة مفتاحية مقسمة لـ Keyword Clusters:

### 1. الصفحات الديناميكية للأدوات (`/tools/[slug]`)
يحتوي المشروع على صفحات مستقلة لكل أداة لرفع تصنيفها في جوجل بشكل منفصل:
- `/tools/whatsapp-marketing` ➔ واتساب ماركتنج وواتساب سندر
- `/tools/telegram-marketing` ➔ تليجرام ماركتنج وتليجرام سندر
- `/tools/facebook-marketing` ➔ فيسبوك بوت ونشر المجموعات
- `/tools/instagram-automation` ➔ انستجرام بوت وأتمتة الـ DM
- `/tools/tiktok-automation` ➔ تيك توك بوت وزيادة التفاعل
- `/tools/data-scraper` ➔ سحب الداتا و Google Maps Scraper
- `/tools/reach-booster` ➔ أداة زيادة الريتش والكلمات المفتاحية
- `/tools/canva-alternative` ➔ بديل كانفا برو للتصميم
- `/tools/video-editor` ➔ مونتاج وتعديل الفيديو
- `/tools/ai-video-generator` ➔ توليد فيديو بالذكاء الاصطناعي
- `/tools/digital-marketing-course` ➔ كورس التسويق الإلكتروني
- `/tools/egypt-marketing-data` ➔ داتا مصر التسويقية

### 2. البيانات الهيكلية (JSON-LD Structured Data)
تم حقن 7 أنواع من المخططات الرسمية لجوجل:
- `Organization Schema` — تعريف العلامة التجارية والواتساب
- `WebSite Schema` — تعريف كينونة الموقع باللغة العربية (مصر)
- `Course Schema` — إظهار الكورس في النتائج كمنتج تعليمي
- `Product Schema` — إظهار الباقة وسعر 300 ج والتقييمات
- `FAQPage Schema` — إظهار كروت الأسئلة الشائعة في نتائج Google (Rich Snippets)
- `ItemList Schema` — عرض الأدوات كـ Carousel في البحث
- `BreadcrumbList Schema` — مسارات التصفح للعملاء وجوجل

### 3. أداء وسرعة التحميل (PageSpeed Insights Optimization)
- إزالة أكواد الـ Polyfills القديمة بواسطة `browserslist` المعتمد في `package.json`.
- تحسين تباين الألوان لقيم يتجاوز 7:1 ليتوافق مع معايير الـ **WCAG AAA Accessibility**.
- ربط عناصر الـ `<select>` بتصنيفات `id` و `htmlFor` و `aria-label` صريحة.
- شريط ماركيه سلس غير متقطع مع تفعيل إمكانية الوصول `tabIndex={-1}` للعناصر المكررة.

## 🛠️ طريقة التشغيل والتطوير المحلّي

لتشغيل المشروع على جهازك المحلي، اتبع الخطوات التالية:

### 1. استنساخ المشروع (Clone Repository)
```bash
git clone https://github.com/belalkaram/growix.git
cd growix
```

### 2. تثبيت الحزم والتبعيات (Install Dependencies)
```bash
npm install
```

### 3. تشغيل سيرفر التطوير (Run Development Server)
```bash
npm run dev
```

افتح المتصفح على الرابط المحلّي: `http://localhost:3000`

### 4. فحص جودة الأكواد والتجميع (Typecheck & Build)
```bash
npx tsc --noEmit
npm run build
```

## 🌐 إعدادات النشر والاستضافة (Deployment)

المشروع جاهز ومحسن بالكامل للنشر الفوري على **Vercel**:

- **النطاق الرسمي:** `https://growix.belalkaram.dev/`
- **نطاق Vercel المربوط:** `https://grow-ix.vercel.app/`
- **301 Permanent Redirect:** تم إضافة تحويل تلقائي في `vercel.json` يحول أي زائر من `grow-ix.vercel.app` إلى `growix.belalkaram.dev` لحماية أرشفة Google وتجنب المحتوى المكرر.
- **Security Headers:** تم تفعيل ترويسات `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy` لحماية البيانات.
